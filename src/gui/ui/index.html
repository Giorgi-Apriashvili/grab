Downloads
After each download, the server computes an MD5 checksum of its copy (md5sum, through grab's own SSH connection) while grab computes yours, here and in the grab command. Both read the file once more, at the same time: about 2 seconds per GB in tests. A copy that differs is deleted and the download fails, so Retry gets it again. A copy that changed on either side since the download, or a server without md5sum, is kept as "not verified".
Speed schedule
Caps the speed of all downloads at these times, in this window and the grab command. Where times overlap, the lower speed wins. Outside them, Limit speed in the status bar applies; a change there during these times lasts until the schedule's next change.
